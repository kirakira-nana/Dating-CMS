pH7Builder インストール
=======================

必要環境: PHP 8.2 以上、MySQL 8.0 以上、composer.json に記載の PHP 拡張。
古い MySQL と MariaDB はこのリリースでは検証・サポートしていません。
バージョン付きリリース ZIP には本番用依存関係が含まれます。
ソースからの導入には Composer 2 が必要です。

初期言語は日本語です。

本番クイックスタート:
https://github.com/pH7Software/pH7-Social-Dating-CMS/blob/18.x/docs/QUICK_START.md

公開チェックリスト:
https://github.com/pH7Software/pH7-Social-Dating-CMS/blob/18.x/docs/LAUNCH_CHECKLIST.md

リリース案内:
https://github.com/pH7Software/pH7-Social-Dating-CMS/tree/18.x/docs

このリリースの Composer インストール:
composer create-project ph7software/ph7builder:18.6.1 pH7Builder-v18.6.1 --no-dev --prefer-dist

その他の配布:
Softaculous: https://www.softaculous.com/apps/socialnetworking/pH7Builder
SourceForge: https://sourceforge.net/projects/ph7socialdating/

Softaculous と SourceForge は GitHub / Packagist より遅れることがあります。
導入やアップグレードの前に、提供バージョンを確認してください。

PHP、MySQL、ウェブサーバーの準備ができていれば、依存関係の導入と案内付き
ブラウザーインストーラーは通常 20〜30 分です。DNS、HTTPS 証明書、
メール事業者の承認は別途です。

インストール後の初期管理パスは /admin123/ です。サイトを使う前に
_install ディレクトリを削除してください。本番ではデバッグ表示をオフにし、
サーバーのメール転送とクロンを設定したうえで、公開前に実際のテスト登録を
完了してください。

問題報告: https://github.com/pH7Software/pH7-Social-Dating-CMS/issues
議論: https://github.com/pH7Software/pH7-Social-Dating-CMS/discussions
